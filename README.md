# الموقع الشخصي (Portfolio) - أكرم عبدالخالق

موقع شخصي متجاوب وبتصميم فاتح مع أنيميشن، يعرض السيرة الذاتية والمهارات وسابقة الأعمال.

## التقنيات
- HTML5
- CSS3 (Animations)
- Bootstrap 5 (RTL) + Bootstrap Icons
- JavaScript بسيط للحركات

## إضافة الصورة الشخصية
ضع صورتك داخل مجلد `images` باسم `profile.jpg` (يُفضّل صورة مربعة).

## تشغيل المشروع
افتح ملف `index.html` في المتصفح مباشرة.

## هيكل الملفات
```
├── index.html
├── style.css
├── script.js
├── images/
│   └── profile.jpg
└── README.md
```

## رفع المشروع على GitHub
```bash
git init
git add .
git commit -m "Add portfolio website"
git branch -M main
git remote add origin https://github.com/USERNAME/portfolio.git
git push -u origin main
```
